# Diretório de Estilos (`src/styles`)

Esta pasta contém as definições globais de folha de estilo da aplicação.

## Conteúdo Ativo

- [index.css](file:///c:/Users/Bruno%20Vieira/OneDrive/%C3%81rea%20de%20Trabalho/Antigravity%20Projects/project_2%20-%20fluxograma%20IA/src/styles/index.css): Arquivo principal de estilos que configura o **Tailwind CSS v4** (`@import "tailwindcss";`), tema de tipografia Inter, variáveis CSS escuras no `:root`, scrollbars personalizados e classes utilitárias modernas (efeito `.glass` e `.shadow-antigravity`).

## Como Usar

O arquivo `index.css` é importado no ponto de entrada global `src/main.tsx`, aplicando a identidade visual por toda a aplicação. A folha legada `App.css` foi transferida com segurança para a pasta `excluir/`.

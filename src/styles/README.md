# Diretório de Estilos (`src/styles`)

Esta pasta contém os arquivos de folha de estilo globais do aplicativo.

## Conteúdo

- [index.css](file:///c:/Users/Bruno%20Vieira/OneDrive/%C3%81rea%20de%20Trabalho/Antigravity%20Projects/project_2%20-%20fluxograma%20IA/src/styles/index.css): Arquivo principal de estilos que configura o **Tailwind CSS v4** e define as cores do tema escuro no `:root` e classes utilitárias personalizadas (ex: `.glass` para efeito de vidro e `.shadow-antigravity` para sombreamento flutuante).
- [App.css](file:///c:/Users/Bruno%20Vieira/OneDrive/%C3%81rea%20de%20Trabalho/Antigravity%20Projects/project_2%20-%20fluxograma%20IA/src/styles/App.css): Folha de estilo legada (herdada do template padrão Vite) disponível como backup para utilitários adicionais.

## Como Usar

Os estilos globais e variáveis de design são injetados na aplicação a partir da importação do `index.css` no ponto de entrada `src/main.tsx`.

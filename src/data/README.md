# Diretório de Dados (`src/data`)

Esta pasta armazena as estruturas de dados estáticos do aplicativo.

## Conteúdo

- [history.ts](file:///c:/Users/Bruno%20Vieira/OneDrive/%C3%81rea%20de%20Trabalho/Antigravity%20Projects/project_2%20-%20fluxograma%20IA/src/data/history.ts): Define a interface TypeScript `AIEra` e contém o array `historyData` com todos os marcos cronológicos da Inteligência Artificial (períodos, títulos de eras, e lista de eventos individuais com anos, títulos e descrições).

## Como Atualizar os Dados

Caso deseje adicionar novos eventos ou alterar marcos históricos na linha do tempo, modifique a coleção contida em `history.ts`. O componente `Timeline` lerá os dados atualizados de forma automática.
